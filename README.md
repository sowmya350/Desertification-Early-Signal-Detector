# Desertification-Early-Signal-Detector

## About the Project

Desertification Early Signal Detector is a machine learning based project used to identify early signs of desertification.

The system analyzes environmental factors such as vegetation, temperature, rainfall and soil conditions to estimate the desertification risk of a particular area.

The main purpose of this project is to detect possible desertification at an early stage and provide a simple risk indication.

## Features

- Environmental data analysis
- Data preprocessing
- Desertification risk prediction
- Low, Medium and High risk classification
- Simple web interface
- Prediction results using machine learning

## Machine Learning

The model uses environmental features such as:

- NDVI
- Temperature
- Rainfall
- Soil condition
- Vegetation condition

Random Forest can be used to predict the desertification risk based on these parameters.
